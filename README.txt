ELVIORA updated project
======================
Files:
- index.html
- rooms.html
- amenities.html
- gallery.html
- account.html (new)
- style.css
- script.js

Keep your existing image files in the same folder as the HTML files.
Open index.html using VS Code Live Server or another local web server.

Account/booking demo:
- Create an account on account.html, then booking is enabled.
- User accounts are stored in localStorage key "elvioraUsers".
- Current login is stored in "elvioraCurrentUser".
- Booking requests are stored in "elvioraBookings".
- Browser localStorage is only for demonstration. Passwords are not safely protected,
  and this does not create a real hotel reservation or server-side account.
